# Instructions: Implementation of a 2D Drawing Application with PySide6, Plugin Support, Parameter Saving, and SVG/DXF Export Functions

Follow the requirements below to implement a 2D drawing preview screen, dynamic plugin loading structure, JSON parameter saving/loading, and SVG/DXF file export functions using PySide6 (Qt for Python).

## Development Environment
- Python 3.12 (Assuming an Embedded environment)
- PySide6 (Qt for Python)
- ezdxf (Third-party library for DXF output)
- OS: Windows 11

## System Requirements and Structure

### 1. Plugin Base Class (`ShapePluginInterface`)
Define a plugin interface base class inheriting from `abc.ABC`.
- **Class Name**: `ShapePluginInterface`
- **Identification Properties**: `plugin_name` (Display name), `plugin_id` (Unique identifier)
- **GUI Generation**: `create_parameter_widget() -> QWidget`  
  An abstract method that creates and returns a GUI for parameter adjustment (e.g., SpinBox, LineEdit).
- **Preview Drawing**: `generate_graphics_item(params: dict) -> QGraphicsItem`  
  An abstract method that generates and returns a `QGraphicsItem` for preview display and manipulation based on the provided parameters dictionary.
- **DXF Conversion Drawing**: `export_to_dxf(msp, params: dict, position: QPointF)`  
  An abstract method that adds CAD entities (LINE, CIRCLE, LWPOLYLINE, etc.) to an ezdxf model space (`msp`), considering the placement coordinates (`position`).
- **Parameter Operations**:
  - `get_current_parameters() -> dict`: Retrieves current GUI input values as a dictionary.
  - `set_parameters(params: dict)`: Reflects received dictionary values into the GUI from an external source.
- **Change Notification**: Define a PySide6 `Signal` (`parameters_changed`) to trigger re-rendering of the preview screen when GUI values change.

### 2. Dynamic Plugin Loader (`PluginManager`)
- Scan `.py` files in the `plugin` folder (automatically generate if it doesn't exist) located in the executable directory using `importlib` / `pkgutil`.
- Implement a manager class that dynamically detects and instantiates classes inheriting from `ShapePluginInterface` to manage them collectively within the application.

### 3. Main Window and Preview Screen (`MainWindow`, `DrawingScene`)
Build based on `QMainWindow`.
- **Left Panel (`QDockWidget` etc.)**:
  - A dropdown (`QComboBox`) to select detected plugins.
  - An area to display the parameter setting GUI (`create_parameter_widget()`) for the selected plugin.
  - Placement control buttons (e.g., "Add to Drawing").
  - **Configuration Management Functionality**: Buttons for bulk saving/loading parameters of all placed shape elements ("Save JSON", "Load JSON").
  - **File Export Functionality**: Buttons for exporting the entire drawing ("Export SVG", "Export DXF").
- **Center Preview View (`QGraphicsView` & `QGraphicsScene`)**:
  - Display the drawing area (paper or canvas) including borders, title areas, etc.
  - Place shapes generated by plugins onto the Scene.
  - Set `QGraphicsItem.ItemIsMovable` and `ItemIsSelectable` flags for generated shapes to **enable manual position adjustment via mouse (drag move)**.
  - Support zooming with the mouse wheel and panning with middle-click drag.

### 4. Configuration Save/Restore Functionality (`ConfigManager`)
- **JSON Saving Process**:
  Implement a function to export/save a single `config.json` file containing "Plugin ID used", "Current parameter values (`get_current_parameters()`)", and "Placement position on the Scene (X, Y coordinates)" for each shape element placed in the Main Window.
- **JSON Loading Process**:
  Implement a function to load the saved `config.json`, regenerate shapes from corresponding plugins, and place them on the Scene at their saved positions/parameters while restoring the GUI state.

### 5. Drawing Export Functionality (SVG / DXF)
- **SVG Export Functionality (`QSvgGenerator`)**:
  Implement a process to output the current graphic representation (shapes, text, borders) from `QGraphicsScene.render()` into a vector format `.svg` file using PySide6's `QSvgGenerator`.
- **DXF Export Functionality (`ezdxf`)**:
  Generate a DXF document with `ezdxf.new()`, iterate through all shape elements on the Scene, call the corresponding plugin's `export_to_dxf()` to add drawing entities to the model space, and save as a `.dxf` file.
